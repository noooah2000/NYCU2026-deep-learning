# NYCU Deep Learning Homework

This repository contains a collection of deep learning assignments completed as part of the NYCU Deep Learning course.

## Overview

The projects in this repository cover key concepts in deep learning, including neural network basics, semantic segmentation, generative models, reinforcement learning, and video prediction. Each assignment is organized in its own folder and corresponds to a separate project.

## Repository Structure

- `lab1/` - Backpropagation and neural network fundamentals
- `lab2/` - Binary semantic segmentation using U-Net and ResNet-U-Net
- `lab3/` - MaskGIT-based image inpainting
- `lab4/` - Conditional VAE for video prediction
- `lab5/` - Deep reinforcement learning with DQN-based tasks
- `lab6/` - Generative model experiments and dataset utilities
- `lab7/` - A2C and PPO for continuous control tasks

## Homework Details

### Lab1
This assignment focuses on backpropagation, activation functions, optimization, and basic neural network implementations.

### Lab2
This assignment explores binary semantic segmentation using U-Net and ResNet-U-Net architectures. It covers dataset handling, training, validation, and inference.

### Lab3
This assignment implements MaskGIT for image inpainting. It focuses on VQ-VAE style latent representation and transformer-based generation.

### Lab4
This assignment introduces conditional VAE models for video prediction. It explores latent variable modeling and temporal forecasting.

### Lab5
This assignment covers deep reinforcement learning with DQN-based tasks and model evaluation across different scenarios.

### Lab6
This assignment focuses on generative models, including diffusion-style training and synthetic data generation for object-conditioned generation tasks.

### Lab7
This assignment introduces A2C and PPO for continuous control tasks, such as Pendulum and Walker environments.
